# DAB-DABPlus-SDR-BER-Evaluation
## Overview
MATLAB-based implementation and evaluation of a DAB/DAB+ communication system using OFDM/QPSK and ADALM-PLUTO SDR. Analyzed BER performance across multiple SNR levels through simulation and wireless transmission, including synchronization, constellation analysis, and theoretical BER comparison.
